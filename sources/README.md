# 内置洛雪音源脚本库

脚本统一来自 [pdone/lx-music-source](https://github.com/pdone/lx-music-source)（各目录 `latest.js`，2026-11-13 同步），版权归原作者所有，本仓库仅作播放器内置分发，脚本内容未做修改。

- 经线上实测可用的源才会在 `manifest.json` 中标记 `verified: true` 并随页面自动挂载
- 仅为实测存活源的快照，上游失效时以 [health-status](https://github.com/pdone/lx-music-source/tree/health-status) 与站点实测为准
